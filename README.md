# 🌸 Aesthetic Login Form

Sebuah tampilan halaman *login* interaktif dengan desain aesthetic bertema **pink & gray**. Project ini dibuat menggunakan HTML5, CSS3, dan JavaScript murni (Vanilla JS) yang dilengkapi dengan validasi *real-time* untuk keamanan dan pengalaman pengguna (*user experience*) yang lebih baik.

## ✨ Fitur Utama

- **Desain Aesthetic & Responsif**: Menggunakan perpaduan warna *soft pink* dan *slate gray* dengan tata letak berbasis Flexbox.
- **Validasi Input Real-Time**:
  - **Nama**: Memastikan field tidak kosong.
  - **Password**: Wajib minimal 8 karakter serta mengandung kombinasi **huruf**, **angka**, dan **simbol**.
  - **Email**: Memeriksa kesesuaian format alamat email standar menggunakan *Regular Expression* (Regex).
- **Struktur Kode Bersih**: Menerapkan atribut `for` pada `<label>` dan `id` unik pada setiap input untuk aksesibilitas yang baik.

## 🛠️ Teknologi yang Digunakan

* **HTML5**: Struktur form dan input data.
* **CSS3**: Penataan layout Flexbox, efek transisi, *hover*, *focus states*, dan pembuatan *soft shadow*.
* **JavaScript (ES6)**: Penanganan event submit, manipulasi DOM, serta validasi pola string dengan Regex.
